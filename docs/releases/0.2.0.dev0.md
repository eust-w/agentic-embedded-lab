# Agentic Embedded Lab 0.2.0.dev0

`0.2.0.dev0` is the first publishable Development Preview of the general embedded
agent experimentation platform.

## Scope

The release provides an agent-facing control plane for classifying embedded
problems, planning experiments, executing explicit simulation backends, comparing
runs, generating bounded models and preserving evidence. It is simulator- and
agent-provider-independent at the contract layer.

## Acceptance

- `foundation`: passed.
- `simulation`: passed in qualified local Linux containers.
- `software`: passed with the local PostgreSQL/MinIO/OIDC/mTLS worker topology.
- `production`: intentionally failed because physical hardware differential,
  calibration, signed Validation Envelopes and human approval are absent.

## Fidelity boundary

This pre-release proves only the named software mechanisms and recorded model
behavior. It does not prove that a real board, peripheral, power rail, radio or
thermal system behaves equivalently.

## Getting started

Follow the repository README and `docs/mcp.md`. The complete local software
acceptance entry point is:

```bash
scripts/run-local-software-acceptance.sh
```
